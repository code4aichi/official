2025年の一般世帯に関する統計です。

分母は「一般世帯数」です（施設等の世帯は含みません）。出典：2025年国勢調査 第8-1表・第6-2表。

2025年の高齢者世帯に関する統計です。

対象は一般世帯。高齢単身：65歳以上の単独世帯。高齢夫婦：夫65歳以上・妻60歳以上の夫婦のみの世帯。3世代世帯は国勢調査の定義に基づきます。各割合の分母は一般世帯総数。出典：2025年国勢調査 第9-1表（b09_01.xlsx）。

2025年の家族構成に関する統計です。

「夫婦と子ども」「父と子ども」「母と子ども」の世帯には成人した子どもも含まれます。「18歳未満の世帯員がいる世帯」は別の集計です。割合の分母は一般世帯総数。出典：2025年国勢調査 第9-1表（b09_01.xlsx）。

2025年国勢調査の住宅統計

各割合の分母は「住宅に住む一般世帯」。持ち家率と借家率の合計は100%とは限りません（間借り等を除くため）。一戸建率・共同住宅率も長屋建・その他を除くため100%とは限りません。出典：2025年国勢調査 第23-4表・第24-4表。

2025年国勢調査の高齢者と住まいの統計

高齢者世帯の持ち家率・借家率は「65歳以上の世帯員がいる住宅に住む一般世帯」を分母とします。65歳以上・75歳以上・85歳以上の人がいる世帯率は一般世帯総数を分母とします。施設等の世帯を含みません。出典：2025年国勢調査 第34-5表・第32-4表。

2025年度学校基本調査（2025年5月1日現在）

学校所在地による集計で、居住人口とは一致しません。小学校・中学校のみ（義務教育学校は含みません）。出典：愛知県「令和7年度学校基本統計確定値」。

数字を読むときの注意

人口増減率は選択年とその直前5年間（2025年は2020年比、2020年は2015年比）です。増減の原因を推測するものではありません。

2020年は年齢不詳補完値で総人口を分母とし、2025年は年齢不詳を除く人口を分母とします。定義が異なるため、高齢化率の年次比較にはご注意ください。

HOW TO READ THE DATA

数字の見方と注意点

2015年・2020年・2025年の国勢調査を収録しています。2025年を初期表示とし、年度を選択できます。人口増減率は5年間の変化を計算しています（2015年は比較する前年度データ未収録）。

高齢化率の定義に注意：2020年は「年齢不詳補完値」を使い総人口を分母に計算。2025年は年齢不詳を除いた人口を分母に計算しています。同一基準の時系列として単純比較しないでください。2015年の年齢構成・高齢化率、2020年の世帯数は今回の表示対象外です。地図の境界は2022年のデータです。

高齢者の暮らし（2025年）：高齢単身世帯は「65歳以上の単独世帯」、高齢夫婦世帯は「夫65歳以上・妻60歳以上の夫婦のみの世帯」を指します。「65歳以上の人がいるすべての世帯」とは異なります。出典：国勢調査 第9-1表。割合は一般世帯数を分母に計算しています。

ABOUT THIS PROJECT

オープンデータを、
まちの発見に。

「ミエルあいち」は、Code for AICHIがつくる市民向けのオープンデータ可視化サービスです。地図と数字から、身近な地域を新しい視点で眺めるきっかけを届けます。

2015年・2020年・2025年の国勢調査を利用しています。2020年と2025年では高齢化率の算出基準が異なります。地図の境界と統計の年度にもご注意ください。

出典・データの取り扱い

人口・年齢構成：愛知県・総務省「2015年・2020年・2025年国勢調査」／境界：国土数値情報を加工した公開GeoJSON
