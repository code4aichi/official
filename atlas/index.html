HOW TO READ THE DATA

数字の見方と注意点

このサービスは、2015年・2020年の国勢調査を比較しています。最新の人口を表しているわけではありません。人口増減率は2015年から2020年の5年間の変化です。

高齢化率は2020年の65歳以上人口÷総人口×100で計算しています。年齢構成には年齢不詳を補完した値を使用しています。地図の境界は人口統計と基準年が異なります。

ABOUT THIS PROJECT

オープンデータを、
まちの発見に。

「ミエルあいち」は、Code for AICHIがつくる市民向けのオープンデータ可視化サービスです。地図と数字から、身近な地域を新しい視点で眺めるきっかけを届けます。

2015年と2020年の国勢調査を利用しています。年齢構成は2020年の「年齢不詳補完値」を採用し、65歳以上人口を総人口で割って高齢化率を算出しています。実際の地図・数字の基準年を確認してご利用ください。

出典・データの取り扱い

人口：愛知県「令和2年国勢調査 人口等基本集計結果」／境界：国土数値情報を加工した公開GeoJSON
