## お問い合わせフォーム（送信設定済み・初回有効化が必要）
- 送信先メールアドレス：`code4aichi@gmail.com`
- 送信サービス：FormSubmit（https://formsubmit.co/）。HTMLのPOST送信を利用します。独自のバックエンドやAPIキーは不要です。
- 入力欄：お名前、メールアドレス、お問い合わせ内容。メールの件名は「【Code for AICHI】ウェブサイトからのお問い合わせ」です。
- スパム対策：FormSubmitの標準CAPTCHAとハニーポットを利用します。
- **必須の初回手続き**：サイト公開後、フォームからテスト送信してください。`code4aichi@gmail.com` に届くFormSubmitの確認メールにある有効化リンクをメール受信者がクリックする必要があります。有効化するまでは通常のメール配信が始まりません。
- **動作確認**：有効化後にもう一度テスト送信し、メール受信と返信先を確認してください。迷惑メールフォルダもご確認ください。
- 送信後はFormSubmit側の完了画面に遷移します。送信の成功はこのZIPの作成だけでは検証できません。
- お問い合わせ情報は第三者サービスに送信されるため、運用開始前にプライバシーポリシーやサービスの利用条件をご確認ください。
