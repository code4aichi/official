# Code for AICHI SHIFT リニューアル

`index.html` をブラウザで開くとサイトを確認できます。画像は `assets/images/`、デザインは `style.css`、操作は `main.js` です。

## 重要: お問い合わせフォーム
元サイトは外部の Mobirise フォームサービス `https://mobirise.eu/` を送信先としていました。移行先での認証や動作が確認できないため、新版は無断で外部送信せず、送信未設定のメッセージを表示する安全な状態としています。本番公開前にフォームサービスまたはバックエンドを接続してください。

## デザイン素材
ロゴマークは提供されたデザイン画像から切り出したPNGです。正式なベクターロゴ（SVG/AI）があれば高品質に差し替えることを推奨します。

## コンテンツ
元の `official-main.zip` から、活動内容、実績一覧、主なプロジェクト説明、画像、SNSリンクを引き継いでいます。2023年以降の新規実績は追加していません。
