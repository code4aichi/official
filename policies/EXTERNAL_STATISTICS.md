# v2.7 新規統計データ取り込みルール

- **2015/2020/2025年国勢調査JSON、および既存 `atlas/app.js`, `atlas/data/indicators.json` は変更禁止**。このパッケージも変更していません。
- メイン取得元はe-Stat API v3、統計LODは補助検索のみ。旧RESAS-APIは使いません。
- APIから取得したデータは `staging/` にのみ保存します。
- 表の次元コード・調査年・分類・単位・地域コード・出典URLを人が確定させ、`config/example_indicator_manifest.json` をもとにマニフェストを作ります。
- **全非地域次元に対する厳密なコード指定**がない場合、取り込みを拒否します。選択年もe-Statの次元指定で絞り込む必要があります。
- **愛知県54市町村のコードがちょうど1件ずつ揃い、値が数値である場合に限って候補JSONを生成**します。未収録、秘匿、区部の混入、重複、合算単位の不一致は拒否します。
- `publish` は人によるレビューと承認トークンが必要です。公開先は新設 `atlas/data/external-statistics/` のみで、既存ファイルの上書きは禁止します。
- 欠損データがある場合は元のAPIデータの品質を確認してから、別設計として取り扱います。欠損をゼロに置換しません。
- e-StatのアプリIDはGitHub ActionsのSecretとして保存。Web画面にAPIキーを埋め込みません。
- 配信サイトは承認済みの指標のみ別タブで閲覧します。人口・高齢化率などの従来の地図色分け・AI解析には自動的に混ぜません。
- メタデータの持つ地域コード体系が5桁と異なる場合、明示的な変換表を設計・レビューするまで取り込みません。
- 新規統計の主題ごとの権利・出典表示・使用条件を確認します。

## 実装範囲と留保

API接続コード、ステージング、形式・網羅性チェック、手動公開、UIの公開済み追加統計表示を実装済みです。実際のe-Statの統計表ID、54自治体データ取得、正誤照合、公開承認は**未実施**です。統計LODは公式エンドポイントを指定する読み取り専用の試験ツールであり、自動マージ機能は未実装です。
