# ミエルあいち v2.9.5｜地図縮小の修正（v2.9.4上書きパッチ）

## 原因と対応
v2.9.4では地図SVGを `width:100%; height:100%` として、高さの大きな親領域に収めていました。これによりSVGの`viewBox`を維持する描画で余白が増え、地図本体が小さく見えることがあります。

v2.9.5は**地図のSVGの表示方法のみ**を再調整します。SVGは横幅基準（`height:auto`）にし、表示の拡大率 `scale(1.22)` をかけます。外側の左右カードの共通高さ・右パネルのスクロールはv2.9.4を維持します。統計データ、自治体境界座標、SVG viewBox、イベント処理は変更しません。

**重要**：SVGの元のviewBoxと図形の余白は現行リポジトリの地図生成コードによって決まります。ブラウザの模型ページでは地図図形の拡大を確認できましたが、実際の54市町村SVGを読み込んだ本番ブラウザでの最終確認は必要です。端が切れる場合は拡大率を小さくする必要があります。

## GitHubへの適用
1. ベース `main` からブランチ `fix/mieru-ui-v295-map-visible-scale` を作成
2. `atlas/ui-v295.css` を**新規追加**
3. `atlas/index.html` を更新（すでに独自変更がある場合は下のlink行だけ追加）
4. PRタイトル：`fix(atlas): restore visible Aichi map scale after v2.9.4`
5. コミット：`fix(atlas): size map SVG by width and enlarge rendered geography`
6. PRをマージ後、ブラウザで強制更新

```html
<link rel="stylesheet" href="./ui-v295.css?v=2950"/>
```

上記のlinkを `ui-v294.css` の読み込みより**後**に、`</head>` より前に入れます。旧CSSは削除不要です。

## 確認項目
- PC 1440×900と1280×800で愛知県全域が収まり、以前より地図本体が大きい
- 豊根村、南知多町など端の自治体が切れていない
- 地図のクリックや自治体選択が従来どおり
- 左右外側カードの下端が揃う
- 右側の追加統計は内部スクロールする
- 390px・430pxのスマホでは従来のレイアウトを維持する

## 検証範囲
- CSS、HTML参照先、ZIP構成の静的検証
- Chromiumで**模擬SVG**を使って表示枠と拡大後の図形を検証（模擬データのため、本番での動作を保証するものではありません）
- 本番リポジトリの全データ・本番サイトへのブラウザアクセスとクリック操作は未検証
