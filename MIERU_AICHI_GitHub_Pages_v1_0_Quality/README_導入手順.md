# ミエルあいち v1.0｜公開品質改善版

## この更新で変更するファイル（3点）
- `atlas/index.html`
- `atlas/styles.css`
- `atlas/app.js`

既存の画像、`atlas/data/historical.json`、`atlas/data/municipalities.json`、`atlas/data/aichi-boundaries.geojson`、GitHub Actionsは**変更しません**。

## 主な改善
1. キーボードによる本文スキップリンクとタブ操作（矢印・Home・End）
2. 地図と市町村ボタンのフォーカス表示・選択状態の読み上げ情報
3. スマホでの指標タブの横スクロール、狭い画面での長い数値や比較カード対策
4. 公式統計の基準年、年齢不詳補完値、境界データの基準年の違いを見つけやすく説明
5. 人口データ取得失敗時の明示的なメッセージ、地図読込中状態の通知
6. CSS・JavaScriptの参照を `?v=100` に変更して旧キャッシュの影響を減らす

## GitHub Pages更新手順
1. https://github.com/code4aichi/official で `main` から `feature/mieru-v10` ブランチを作成。
2. GitHubの `atlas/` を開いて、上記3ファイルを**同名で上書き**。
3. Pull Requestを作成して **変更が3ファイルだけ**であることを確認。
4. マージ後、https://code4aichi.org/atlas/ をPCとスマートフォンで確認。
5. 不具合時はPRをRevertすれば戻せます。元のGeoJSONや画像ファイルは触らないでください。

## 動作確認のポイント
- 地図の54市町村を選択でき、人口・増減・高齢化率が正しいこと
- PCでTabを押すとスキップリンクが表示され、地図へ移動できること
- データタブを選択した後、左右の矢印キーおよびHome/Endで移動できること
- 画面幅375px程度でもテキストやカードがはみ出ないこと
- 「数字の見方と注意点」と出典リンクが表示されること
