# ミエルあいち v2.9.20 — 画面構成と操作性の整理

## 変更内容

- 市町村・年度・分野・指標の4欄を、横幅いっぱいの均等な列に配置。市町村欄の旧margin-left:autoを解除。PCは4列、1059px以下は2列。
- 右上の縮小地図を含む装飾用地図の生成を廃止。実際の地図SVGと選択イベントは維持。
- 地図画面：地図と選択中の指標の値・出典、基本情報へのボタンに集中。
- 基本情報画面：地図を重ねず、人口・暮らし・分野別の詳細を全幅で表示。「詳しく見る」で分野を切替。
- 比較：2自治体の条件を上段に揃え、その下に結果・比較グラフを表示。
- ランキング：指標と並び順の操作をまとめ、結果を全幅で表示。
- 追加統計：自治体一覧をPC3列、タブレット2列、スマートフォン1列に整理。
- 発見・注目点・レポート・AI・人口推移・まちの特徴：機能ごとの案内と全幅の結果領域を整備。
- 二次機能は「発見・まとめ」に集約。スマートフォンでは折り畳み、縦の占有を抑制。
- スマートフォンでは人口カードを1列にし、冗長な利用可能指標カードを非表示。
- 世帯数の表示を見出し＋数値に統一。「詳しく見る」の文字が詰まる高さ・余白を修正。

## 自動検証の再実行

Node.jsとPlaywright、Chromiumを利用してください。
通常のPlaywright実行環境では以下を実行します。

```
node tests/atlas_v2920_acceptance.cjs
```

別のChromiumを利用する場合は `MIERU_CHROMIUM` に実行ファイルの絶対パスを指定できます。
任意の日本語フォントCSSを使用する場合は `MIERU_TEST_FONT_CSS` に絶対パスを指定できます。
テストは一時的なlocalhostサーバーを自動で起動・終了し、artifacts/v2920/results.jsonを出力します。
